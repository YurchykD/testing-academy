How test cases are designed: from the specification (black-box) or from the code structure (white-box).

ISTQB terminology: CTFL v4.0.1 explicitly addresses functional, non-functional, black-box and white-box test types. Performance efficiency, compatibility, usability and security are non-functional quality characteristics. Regression and confirmation testing are change-related testing. This learning app groups related concepts for practice and labels their relationship.
